## 已确定的边界

- AI 整理仅处理日历所选当天的未完成任务，不扫描全部收件箱；没有明确时间则保持「随时」。
- 清单为 Inbox / Work / Study / Life；筛选、编辑复用现有页面，不新建独立清单页。
- One Thing 与锁定都是属性，不改变「随时 / 时间轴」分组，容量只计一次；不恢复独立「今日必做」区。
- 个人页面必须登录。通知已有全部已读与确认清空，清空持久隐藏并保留去重记录；这些不是待开发项。
- 无日期任务已有收件箱「未安排」入口，不自动改成今天。
- 沿用已有添加入口，不增加右上角快速添加或 N 快捷键；收件箱不提供清单、标签、状态筛选下拉菜单（最新需求，覆盖早期计划）。
- 任务、子任务、偏好与通知已云端持久化；首屏仅加载未完成任务与今天完成项，历史按需读取，搜索走服务端分页。Realtime 事件触发工作区快照回读，但串行写入与 Realtime 都不是完整离线支持。
