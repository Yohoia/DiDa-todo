## 本次发现的待修复项

### AUDIT-01：存储不可写时，普通编辑没有上传路径（P1）

位置：`src/features/tasks/task-write-queue.ts:41–84`、`workspace-provider.tsx:340–347,578–584`。

`enqueueTaskWrite` 只尝试保存到 localStorage，异常被吞掉；Provider 未保留其返回的队列，而上传循环重新从 localStorage 读取。存储被禁用或配额耗尽时，界面仍乐观更新，但待写队列为空，在线也不会上传普通编辑、完成勾选等操作。刷新或远端快照回读后，这些修改可能丢失。

隔离复现使用真实队列函数与抛出配额错误的存储替身：入队函数返回 1 条，上传时可读取条目为 0。现有“bad task-write storage”测试只检查不抛异常，未检查修改最终上传。

建议：增加按账号隔离的内存队列或可靠的直写降级，同时显示无法持久保留待写数据的状态；验证存储失败且网络正常时仍会保存。

### AUDIT-02：子任务并发写入可静默覆盖（P1）

位置：`src/lib/data/repository.ts:514–548`。

纯子任务更新跳过任务行条件更新，直接整组 upsert 并删除未列出的子任务。它既不校验 `expectedUpdatedAt`，也不推进任务行版本。两个设备基于同一旧快照编辑时，第二次写入可覆盖标题/完成状态，或删除第一端新增的子任务。

隔离复现调用真实 `updateTaskVersioned`，数据库请求使用替身：两次同版本的纯子任务写入都被接受，最终保留第二端的旧编辑，任务表读取/写入次数为 0。迁移中的子任务归属约束保护跨账号访问，但没有补上此并发版本协议。

建议：用数据库事务把版本校验、任务版本推进及子任务整组更新合并；补双端子任务编辑和新增/删除冲突验收。计划中“并发不静默覆盖”的完成结论应限定为已经验证的任务行字段。

### AUDIT-03：每日目标进度错误使用整月累计（P2）

位置：`src/features/insights/insights-page.tsx:51–54,163–168`。

“每日专注目标”的进度与无障碍数值均为 `focusMinutesThisMonth / dailyFocusGoalMinutes`。例如昨日已经完成 120 分钟、今天 0 分钟、每日目标 120 分钟时，今天仍显示满进度。

证据为当前渲染公式与中英文“每日目标”文案；未进行登录浏览器复现。建议使用账户时区今天的专注事实计算，并保持月度累计单独展示，补跨午夜重置验证。

### AUDIT-04：AI 周回顾的完成任务历史是假零（P2）

位置：`src/features/insights/ai-advisor-panel.tsx:48–55`、`insights-service.ts:8`。

请求最近 7 天历史时，每天 `completed` 固定为 0；Insights 的逐日数据类型也只有专注分钟，没有真实逐日完成数。用户完成任务但没专注时，顾问得到的仍是零完成数据。接口要求模型基于输入事实回顾，无法自行纠正错误输入。

证据为请求构造与类型定义；未调用真实 LLM。建议提供服务端逐日完成事实，或移除没有真实数据的字段并明确回顾范围。

### AUDIT-05：AI 顾问预览会因任务变化再次请求并重置草稿（P2）

位置：`src/features/insights/ai-advisor-panel.tsx:32–47,58–84`。

候选数组依赖整个 `tasks` 引用，收费请求的 effect 又依赖候选数组。弹窗打开时，工作区任务快照变化，即使只是另一条任务变动，也可能触发新请求；成功回调无条件清空人工草稿并重新全选。期间还可能继续显示上一份可应用的建议，因为 effect 重跑时没有切回 loading。

此项由依赖链与回调逻辑确认，未进行真实收费请求或浏览器交互复现。建议按用户点击生成时冻结快照，数据改变提示建议已过期；由用户明确重新生成，保留或明确处理人工草稿。

### AUDIT-06：AI 顾问“已应用”不是保存成功反馈（P2）

位置：`src/features/insights/ai-advisor-panel.tsx:93–116`、`workspace-provider.tsx:535–584`。

应用调用的 `updateTask` 返回 void，只修改本地状态并排队；弹窗随即提示已应用并关闭，数量使用勾选建议数而非真实保存成功数。后续云端冲突、断网或写入失败可能没有保存。已经不存在的任务会被跳过，仍计入该提示。

证据为真实调用链；未制造生产写入失败。建议区分“待同步”和“保存成功”，给出逐项成功/跳过/失败状态；与当日 AI 整理的应用反馈规则对齐。
