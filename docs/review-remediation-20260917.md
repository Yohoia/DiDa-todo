## 保存与安全边界

- AI 冲突跳过该条，显示应用/跳过/失败数量。版本条件使用现有 `updated_at`，无需新增迁移。
- 专注重放同 ID，不新增记录；旧检查点不缩短时长或撤销完成，不重复计入经验。
- 系统强杀不保证执行离开事件，周期检查点缩小丢失窗口。禁用/清空浏览器存储时无法保留本地日志，仍尝试云端保存。后续 FOCUS-01 已补当前标签页刷新恢复和休息周期，见 [阶段交付记录](stage-delivery-20260917.md)；通用离线队列仍待 SYNC-01。
- UI 验证不是云端授权：Auth 直接密码 API 由 Supabase 配置控制，Secure password change 有近期登录例外。[官方说明](https://supabase.com/docs/guides/auth/password-security) 本次未修改生产策略。
